# Meghvāhana Sānkr̥tyāyan portfolio — manual GitHub Pages upload

This is a static one-page site. It needs no backend, package installation, or build step. Read `GITHUB-GUIDE.md` for complete publishing and editing instructions.

The **Thunder · Off** control enables one procedural thunder strike whenever a section arrives. The sound is generated by the browser, so there are no audio files to upload.

## Publish it

1. Extract this ZIP. Do not upload the ZIP itself to GitHub.
2. Create a GitHub repository. A public repository works with GitHub Free.
3. In the repository, choose **Add file → Upload files** and upload all extracted files into the repository root. Commit the upload.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then **Save**.
5. GitHub will show the live address in the Pages settings once publishing finishes. For a normal project repository, the address is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

`index.html`, `content-data.js`, `sky-data.js`, `projects-data.js`, and `meghavahana-aura.png` must stay together in the same folder. The extra `.nojekyll` file keeps GitHub Pages from processing the site with Jekyll.

## Edit the main sections

Edit only `content-data.js` to change the name, CV, GitHub, author page, or article links. The file contains plain examples and accepts either full web addresses or local filenames such as `cv.pdf`.

To change the displayed name, replace the text in `name: "Meghvāhana Sānkr̥tyāyan",` and commit the file. Keep the quotation marks and final comma.

## Add or edit projects

Only edit `projects-data.js`. Copy the example project block in its comment, paste it inside `window.portfolioProjects = [ ... ];`, and change the title, description, and URL. Separate multiple project blocks with commas. Save and commit that one file; the Projects section updates automatically.

If a project has no public page yet, use `url: ""`. It will still appear without being clickable.

## Before sharing

The CV and GitHub sections are still placeholders. Add their URLs in `content-data.js` before sharing. The author section already links to the Tulasi Vanam author page and two selected articles.

The astronomical sky data is included locally in `sky-data.js`. The page acknowledges the Stellarium Indian sky-culture source and its CC BY-SA license in the footer; retain that attribution when editing.
